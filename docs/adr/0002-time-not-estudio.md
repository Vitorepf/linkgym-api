# Time, not estúdio

The brand container is a **Time**: the we around one personal (name, logo, accent). The phone never prints that word — only `Fred` or `Iron Lab`. SQL stays `studios`.

Estúdio named a room. Assessoria named a hire. Printing “Time Fred” would put a type between them, so the chrome stays the name alone. Turma stays the student list of that Time; liga the ranking; ofensiva stays on the vínculo, not a shared team streak.
